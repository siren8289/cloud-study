# 리눅스 파일 시스템과 권한 학습 기록

## 목표
- 리눅스 파일 권한(소유자·그룹·기타, r·w·x)의 구조를 이해한다.
- chmod로 숫자 모드와 기호 모드를 직접 적용해 본다.

## 배운 개념
- 권한은 소유자(u), 그룹(g), 기타(o) 세 대상에 각각 r(4), w(2), x(1)로 설정된다.
- 숫자 모드는 각 자리 값을 더한 8진수이다. 예: rw- = 6, r-- = 4, 644 = rw- r-- r--.
- 기호 모드는 u/g/o와 +, -, = 연산자로 권한을 더하거나 뺀다.
- ls -l 첫 글자는 파일 종류(-: 일반 파일, d: 디렉터리, l: 심볼릭 링크)를 뜻한다.
- 소유자 권한 rwx는 파일을 읽고, 수정하고, 실행할 수 있다는 뜻이다.

## 구현 내용
- permission_demo.sh: 빈 파일 생성 후 644 적용, g+w 추가, u+x 추가 과정을 ls -l로 확인

## 실행 결과
- 2단계: -rw-r--r-- (644 적용)
- 3단계: -rw-rw-r-- (g+w 적용)
- 4단계: -rwxr--r-- (u+x 적용)
